# Planejador de Viagem (exemplo)

Arquivos criados:
- `index.html`
- `styles.css`
- `script.js`
- `hotels.json`

Como usar:
1. Abra `index.html` no navegador (duplo-clique ou use um servidor local).
2. Pesquise hotéis, clique em "Reservar" e preencha o formulário (simulação, armazenado no localStorage).
3. Adicione pontos turísticos ao seu itinerário.

Observações:
- Este é um exemplo estático sem backend. Reservas e itinerário são salvas em `localStorage`.
